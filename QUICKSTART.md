# 🚀 Quick Start Guide

## Running REVITALIZE Locally

Follow these simple steps to see your wellness store website in action:

### Step 1: Open Terminal
Open your terminal or command prompt in the project directory.

### Step 2: Run the Server
Type this command:
```bash
npm start
```

### Step 3: View the Website
The website will automatically open in your browser at `http://localhost:3000`

## What You'll See

When the website loads, you'll see:

1. **Navigation Bar** - REVITALIZE logo with Home, Products, About, Contact links
2. **Hero Section** - Beautiful green gradient banner with "Welcome to REVITALIZE"
3. **Product Grid** - 6 wellness products you can interact with:
   - 🧘 Yoga Mat Pro ($49.99)
   - 💪 Fitness Tracker ($129.99)
   - 🌿 Essential Oils Set ($39.99)
   - 🎧 Meditation Headphones ($89.99)
   - 💆 Massage Device ($159.99)
   - 🌡️ Smart Thermometer ($29.99)
4. **About Section** - Information about the store
5. **Contact Form** - Way for customers to reach out

## Try These Features

### Interactive "Add to Cart" Buttons
Click any "Add to Cart" button to see:
- An alert showing the product was added
- The button temporarily changes to "Added!" with a green color
- After 2 seconds, it returns to normal

### Smooth Navigation
Click the navigation links (Home, Products, About, Contact) to smoothly scroll to each section.

### Contact Form
Fill out the contact form and click "Send Message" to see how form submission works.

### Scroll Animations
Scroll down the page and watch the product cards fade in with a smooth animation!

## Stopping the Server

To stop the local server, press `Ctrl+C` (or `Cmd+C` on Mac) in the terminal.

## Alternative Ways to Run

Don't have Node.js? No problem! Check the main README.md for alternative methods using Python.

## Need Help?

- The website uses pure HTML, CSS, and JavaScript (no frameworks)
- All code is in: `index.html`, `styles.css`, and `script.js`
- The design is fully responsive and works on mobile devices too!
